# Java-Practical-Programs ☕

A curious collection of Java practical programs covering all Object-Oriented Programming topics for BTech CSE.

---

## 📌 About This Repository

This repository is a complete set of Java programs focused on Object-Oriented Programming concepts taught in Computer Science & Engineering.  
Each program is written to be simple, well-structured, and easy to run for learning and revision.

---

## 🛠️ Topics Covered

- Classes and Objects  
- Constructors  
- Inheritance  
- Polymorphism  
- Abstraction  
- Interfaces  
- Encapsulation  
- Method Overriding & Overloading  
- Packages  
- Exception Handling  
- File Handling  
- Multithreading  
- Collections Framework
